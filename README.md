# The Beatles: A Tribute

This repository contains the source code for a tribute website dedicated to the legendary rock band, The Beatles.

The live website can be viewed here: [https://gwangmindo123.github.io/webprogramming2/](https://gwangmindo123.github.io/webprogramming2/)

## 소개 (Introduction)

비틀즈는 1960년 영국 리버풀에서 결성된 록 밴드입니다. 존 레논, 폴 매카트니, 조지 해리슨, 링고 스타로 구성된 비틀즈는 대중음악 역사상 가장 영향력 있고 상업적으로 성공한 밴드로 평가받고 있습니다.

## 멤버 (Members)

*   **존 레논** (리듬 기타, 보컬)
*   **폴 매카트니** (베이스 기타, 보컬)
*   **조지 해리슨** (리드 기타, 보컬)
*   **링고 스타** (드럼, 보컬)

## 역사 (History)

비틀즈는 1962년 첫 싱글 'Love Me Do'를 발표하며 데뷔했습니다. 이후 'Please Please Me', 'She Loves You', 'I Want to Hold Your Hand' 등 수많은 히트곡을 발표하며 전 세계적인 인기를 얻었습니다. 1970년 공식 해체하기까지 10년간 활동하며 대중음악계에 큰 족적을 남겼습니다.

## 대표 앨범 (Discography Highlights)

*   Please Please Me (1963)
*   A Hard Day's Night (1964)
*   Rubber Soul (1965)
*   Revolver (1966)
*   Sgt. Pepper's Lonely Hearts Club Band (1967)
*   The Beatles (White Album) (1968)
*   Abbey Road (1969)
*   Let It Be (1970)
